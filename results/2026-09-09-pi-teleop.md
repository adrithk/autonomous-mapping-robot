- Later controller responses showed both controllers active. User reported encoder
  position changed with hand rotation; per-wheel direction/calibration not recorded.
- Hold-to-run WASD reportedly twitched even at 0.10 m/s. A two-second continuously
  published 0.10 m/s command with subsequent zero commands reportedly worked properly.
  This supports investigating keyboard repeat; it does not prove the root cause.
