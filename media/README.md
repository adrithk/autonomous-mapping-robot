# Physical mapping and autonomous path planning

The [README demo](../README.md#demo) presents these assets in workflow order:

| Artifact | File |
|---|---|
| Physical robot during teleoperated mapping | [Robot photograph](real-room/teleoperation-robot.jpg) |
| Room map displayed in RViz | [Map photograph](real-room/teleoperation-slam-map.jpg) |
| Robot navigating the room with Nav2 | [Physical recording](real-room/nav2-robot.mp4) |
| RViz view during navigation | [RViz recording](real-room/nav2-rviz.mp4) |

The photographs show manual driving with automatic SLAM map building. The videos
show autonomous path planning and navigation on the saved map, with destinations
selected by the operator. Clickable poster frames link to each full-length MP4.
Original input files remain unchanged outside Git.

[Setup, provenance and observations](../results/2026-09-10-real-room-mapping-navigation.md).
